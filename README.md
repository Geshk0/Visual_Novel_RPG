# Визуальная новелла с пошаговой боевой системой

Учебный командный проект по дисциплине "Проектная деятельность". Представляет собой игровой прототип на движке Ren'Py, объединяющий жанр интерактивной литературы и тактическую пошаговую боевую систему.

**Главная особенность:** результат боя напрямую влияет на развитие сюжета. Поражение — это не окончание игры, а альтернативная ветка повествования.

## Визуализация

## Основные возможности (Features)

- **Интерактивный сюжет:** чтение текста, вывод спрайтов и фонов, система выборов, влияющих на историю.
- **Пошаговая боевая система:** очередь ходов определяется параметром "Инициатива".
- **Уникальные способности:** персонажи могут использовать атаки, защиту и специальные приемы, расходующие MP.
- **Сюжетный проигрыш:** победа или поражение в бою записывается в флаги состояния и меняет дальнейший ход сюжета.
- **Сохранение прогресса:** возможность сохранять и загружать текущее состояние игры.

## Технологический стек

- **Движок:** [Ren'Py](https://www.renpy.org/)
- **Язык программирования:** Python 3 (для реализации боевой системы и логики)
- **Разметка интерфейса:** Ren'Py Script
- **Система контроля версий:** Git / GitHub

## Установка и запуск

Для запуска проекта на вашем компьютере должен быть установлен [Ren'Py SDK](https://www.renpy.org/latest.html).

1. Склонируйте репозиторий:
git clone https://github.com/Geshk0/Visual_Novel_RPG.git

2. Откройте Ren'Py Launcher (среда разработки движка).

3. В списке проектов нажмите «Обзор» (Preferences -> Projects Directory) и укажите папку, куда вы склонировали репозиторий.

4. Выберите проект в списке и нажмите «Запустить проект» (Launch Project).

(Также вы можете скачать уже собранную версию игры в разделе Releases).
